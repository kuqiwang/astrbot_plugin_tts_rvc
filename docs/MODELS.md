# RVC 模型：从哪来、怎么导入、怎么不出错

## 一、需要哪两个文件

| 文件 | 作用 | 是否必须 |
| --- | --- | --- |
| `xxx.pth` | RVC 声学模型，决定「像谁」 | 必须 |
| `xxx.index` | 特征索引，提升音色相似度 | 强烈建议 |

RVC v2 模型通常还带采样率信息（32k / 40k / 48k），rvc-next 会自动识别，不用手动填。

> 只有 `.pth` 也能用，但音色会飘一些；有 `.index` 时把 `INDEX_RATE` 保持在 0.6~0.8 之间最稳。

---

## 二、模型从哪来

1. **自己训练**：rvc-next 自带训练页（<http://127.0.0.1:7868> → 训练），需要一段干净人声（10 分钟以上效果较好）。
2. **社区模型**：各种 RVC 模型站 / 群文件。下载前确认：
   - 是 **RVC v2**（v1 也能跑，但质量差）；
   - 作者允许二次使用；
   - 不要用来冒充真人或做违法用途。

> 本项目**不附带任何角色模型**。模型版权由使用者自负。

---

## 三、导入步骤

1. 确认语音服务已启动（`启动语音服务.bat`）；
2. 浏览器打开 <http://127.0.0.1:7868>；
3. 找到 **模型库 / Models** 页面；
4. 点 **导入 / Import**；
5. 把 `.pth` 和 `.index` 一起拖进去（或点选择文件）；
6. 填写：
   - **id**：纯英文，例如 `xilian`、`my_voice_01`；
   - **显示名**：随便，中文也行；
7. 提交，等待导入完成；
8. 打开 <http://127.0.0.1:9880/voices>，能看到这个 id 就成功了。

### id 的硬性规则

- **只能用英文字母、数字、下划线、短横线**；
- **不要用中文**：Windows 上 faiss 打不开包含中文的索引路径，会报错或直接静音；
- 不要用空格。

---

## 四、让它成为默认音色

三种方式，任选：

1. **插件配置**：AstrBot 面板 → 插件 → TTS-RVC → `voice_id` 填模型 id；
2. **服务配置**：`service\.env` 里 `VOICE_ID=xilian`，重启语音服务；
3. **临时切换**：QQ 里发 `/voice_set xilian`（只对当前会话生效）。

> 都不填时，服务会自动用模型库里的第一个模型。

---

## 五、调参：像不像、自不自然

改 `service\.env` 后重启语音服务。

| 现象 | 调什么 |
| --- | --- |
| 声音不像目标角色 | 提高 `INDEX_RATE`（0.8~0.9），确认 `.index` 已导入 |
| 有电流声 / 沙哑 | 降低 `INDEX_RATE`，或降低 `PROTECT`（0.25 左右） |
| 齿音重、喷麦 | 降低 `PROTECT` 到 0.2~0.25 |
| 男声底转女声模型发闷 | `PITCH=12`；女转男用 `-12`；同性别保持 0 |
| 语速太快/太慢 | 改 `TTS_VOICE` 换底声，或关掉情绪映射对比 |
| 情绪太夸张 | `EMOTION_SCALE=0.7` |
| 完全不想情绪 | `EMOTION_ENABLED=0` |

## 六、常见报错

| 报错/现象 | 原因 | 处理 |
| --- | --- | --- |
| `faiss read_index` 失败 | 模型 id 或路径含中文 | 改成英文 id 重新导入 |
| 导入后 `/voices` 为空 | 导入没提交成功 | 回 7868 面板看模型库列表 |
| 合成报 `sample rate` 不匹配 | 底声与模型采样率差太多 | 换 `TTS_VOICE` 或换模型 |
| 一合成 CUDA out of memory | 显存不足 | 串行已是默认；关掉游戏/浏览器硬件加速 |
| 声音是原声 | `PITCH` 不对 / 模型没加载 | 看 `/health` 里的 `voices`，再试 `/voice_test` |
| 声音断断续续 | 文本太长或机器卡顿 | 调低插件 `max_chars` |
